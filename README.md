## Featured projects

### [Energy-Aware Robot Control with Lightweight DQN](https://github.com/joelmayinja/energy-aware-robot-dqn)

**Research prototype · Python · PyTorch · Gymnasium · PyBullet · Flask**

Explores energy-aware control of a simulated KUKA iiwa robot. The repository includes a Gymnasium/PyBullet environment, DQN teacher-training code, energy metrics, and a multi-section dashboard. Model distillation, Raspberry Pi deployment, and grid-instability evaluation are planned research stages—not completed results.

### [Agricultural Services Database](https://github.com/joelmayinja/database-submission)

**Team project · MySQL 8**

A relational database project for managing agricultural services and the coffee value chain, including farmers, production seasons, and input distribution. The project documents its schema, role-based access, stored procedures, triggers, analytical views, and test cases.

### [Tax-X: Tax Defense & Deduction Tracker](https://github.com/joelmayinja/Smart_tax_defense_System)

**Python · CSV · Logging**

A modular transaction-audit utility that explores categorizing potentially deductible expenses. The project emphasizes input handling, custom exceptions, and logging. It is an academic software project, not tax or legal advice.

### [Website Exhibit](https://github.com/joelmayinja/website-exhibit)
